## 📖 The Story

Generative design used to mean asking an AI for a picture, getting back a flat, uneditable PNG, and having to start completely over when a single word was misspelled or a card was off-center.

We built **Auxweave** on the emerging **W3C WebMCP (Web Model Context Protocol)** specification so AI agents can work *inside* your canvas. By exposing vector operations directly via `document.modelContext.registerTool()`, humans and AI agents manipulate the exact same live artboard in real-time—combining natural language intent with direct spatial control.

```
┌────────────────────────────────────────────────────────┐
│                    Auxweave Canvas                     │
│   (Shared Live Scene Graph: Text, Shapes, Containers)  │
└───────────────┬────────────────────────▲───────────────┘
                │                        │
    Live Visual Perception     Real-Time Tool Execution
                │                        │
┌───────────────▼────────────────────────┴───────────────┐
│         W3C WebMCP Standard (document.modelContext)     │
│  create_flex_container | validate_layout | align_objects│
└───────────────▲────────────────────────▲───────────────┘
                │                        │
        Local User Edits         AI Co-Designer
    (Mouse, Keyboard, Touch)  (In-App or Chrome DevTools)
```

## 🌟 Highlights

- 📐 **Web-Native Layout Primitives**: Agents invoke Flexbox semantics (`direction`, `gap`, `padding`) resolved by a sub-pixel layout solver.
- 🤝 **Bi-Directional Collaboration**: Every element generated by the agent is instantly selectable, editable, and movable by you.
- 🎨 **Visual Moodboard Grounding**: Agents sample colors and reference imagery directly from user-curated moodboards.
- ✅ **Automated Design QA**: Built-in auditors check typography contrast (WCAG) and boundary overlaps with one-click auto-repair.

## 🛠️ WebMCP Tool Catalog

Auxweave registers **17 WebMCP tools** onto `document.modelContext`:

| Category | Registered WebMCP Tools | Purpose |
| :--- | :--- | :--- |
| 📐 **Layout** | `create_flex_container`, `wrap_in_flex_container`, `apply_poster_template` | Auto-layout containers, grouping & typographic poster scaffolding |
| 🎨 **Primitives** | `add_text_element`, `add_shape_primitive`, `add_hugeicon_symbol`, `add_image_element` | Vector text hierarchy, geometric shapes, icons & images |
| 🔄 **Transform** | `update_transform`, `align_objects`, `apply_color_palette` | Spatial alignment, scaling, rotation & palette application |
| 🔍 **Inspection** | `get_canvas_scene_state`, `get_selected_elements`, `get_document_metadata` | Real-time artboard bounds, active selection & canvas state |
| 🧪 **QA & Moodboard**| `validate_layout`, `repair_layout`, `get_moodboard_content`, `place_moodboard_image` | WCAG contrast checks, layout collision repair & moodboard sampling |

## 🏗️ Tech Stack

- **Frontend**: React 19, TypeScript, Vite, TanStack Router, Tailwind CSS
- **Scene Engine**: Local-first vector scene graph backed by Zustand & custom Flex layout solver
- **Protocol**: Standard W3C WebMCP bridge (`webmcp-bridge.ts`, `webmcp-registry.ts`)
- **Storage**: Browser-local IndexedDB persistence with JSON import/export
