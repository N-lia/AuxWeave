Auxweave is a browser-first vector design studio where **humans and AI agents co-create on the exact same live canvas in real-time**. Built on the emerging **W3C WebMCP (Web Model Context Protocol)** specification, Auxweave bridges direct spatial manipulation and autonomous AI design assistance.

🌐 **Live Application**: [https://aux-weaver.vercel.app/](https://aux-weaver.vercel.app/)

---

## ⚡ The WebMCP Solution

Instead of generating static flat bitmaps (PNG/JPEG) or struggling with 2D coordinate math in LLM text tokens, Auxweave exposes internal canvas operations directly to browser AI models via **`document.modelContext.registerTool()`**.

```
┌────────────────────────────────────────────────────────┐
│                    Auxweave Canvas                     │
│   (Shared Live Scene Graph: Text, Shapes, Containers)  │
└───────────────┬────────────────────────▲───────────────┘
                │                        │
    Live Visual Perception     Real-Time Tool Execution
                │                        │
┌───────────────▼────────────────────────┴───────────────┐
│         W3C WebMCP Standard (document.modelContext)     │
│  create_flex_container | validate_layout | align_objects│
└───────────────▲────────────────────────▲───────────────┘
                │                        │
        Local User Edits         AI Co-Designer
    (Mouse, Keyboard, Touch)  (In-App or Chrome DevTools)
```

---

## 🌟 Key Features

- 📐 **Web-Native Layout Primitives (`create_flex_container`)**: Agents construct responsive compositions using Flexbox semantics (`direction`, `gap`, `padding`) resolved by Auxweave's layout solver.
- 🤝 **Bi-Directional Collaboration**: Every element generated by the agent is instantly selectable, editable, and movable by the human designer on the live canvas.
- 🎨 **Visual Moodboard Grounding**: Agents sample colors and reference imagery directly from user-curated moodboards (`get_moodboard_content`).
- ✅ **Automated Design QA (`validate_layout` & `repair_layout`)**: Built-in layout auditor checks typography contrast (WCAG), margin safety, and element overlap with auto-repair.

## 🛠️ WebMCP Tool Catalog

Auxweave registers **17 modular WebMCP tools** directly onto `document.modelContext`:

| Category | Registered WebMCP Tools | Purpose |
| :--- | :--- | :--- |
| 📐 **Layout** | `create_flex_container`, `wrap_in_flex_container`, `apply_poster_template` | Auto-layout containers, grouping & typographic poster scaffolding |
| 🎨 **Primitives** | `add_text_element`, `add_shape_primitive`, `add_hugeicon_symbol`, `add_image_element` | Vector text hierarchy, geometric shapes, icons & images |
| 🔄 **Transform** | `update_transform`, `align_objects`, `apply_color_palette` | Spatial alignment, scaling, rotation & palette application |
| 🔍 **Inspection** | `get_canvas_scene_state`, `get_selected_elements`, `get_document_metadata` | Real-time artboard bounds, active selection & canvas state |
| 🧪 **QA & Moodboard**| `validate_layout`, `repair_layout`, `get_moodboard_content`, `place_moodboard_image` | WCAG contrast checks, layout collision repair & moodboard sampling |

## 🧪 Testing WebMCP

### Method 1: In-App AI Co-Designer
1. Open [**`https://aux-weaver.vercel.app/create`**](https://aux-weaver.vercel.app/create).
2. Click the **Magic / Agent** icon in the right toolbar and select your AI provider.
3. Prompt: *"Create a modern dark event flyer for Auxweave 2026 with a vibrant accent card"*.

### Method 2: Chrome DevTools WebMCP Panel
1. Open Google Chrome with the [WebMCP Extension](https://github.com/GoogleChromeLabs/web-model-context-protocol) (or `chrome://flags/#enable-webmcp-testing`).
2. Navigate to [**`https://aux-weaver.vercel.app/create`**](https://aux-weaver.vercel.app/create) and open DevTools (`F12`).
3. Select the **WebMCP** panel to view and execute all registered Auxweave tools live in the browser context.

---

## 🏗️ Architecture

- **Frontend**: React 19, TypeScript, Vite, TanStack Router, Tailwind CSS.
- **Scene Engine**: Local-first vector scene graph backed by Zustand & custom Flex layout solver.
- **Protocol**: Standard W3C WebMCP bridge (`webmcp-bridge.ts`, `webmcp-registry.ts`).
- **Storage**: Browser-local IndexedDB persistence with JSON import/export.
